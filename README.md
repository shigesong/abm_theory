# abm_theory

This repository contains Agent-Based Modeling (ABM) simulations and experiments.

## Contents

### Monty Hall Problem Simulation

`monty_hall.nlogo` - A NetLogo simulation of the famous Monty Hall problem that demonstrates the counter-intuitive probability result where switching doors gives you a 2/3 chance of winning, while staying with your original choice gives only a 1/3 chance.

#### How to Use

1. Open `monty_hall.nlogo` in NetLogo (download from https://ccl.northwestern.edu/netlogo/)
2. Click "Setup" to initialize the simulation
3. Choose a strategy: "stay" or "switch"
4. Click "Play One" to see a single game, or "Play Multiple" to run many trials
5. Watch the statistics converge to the theoretical probabilities!

#### Features

- Visual representation of the three doors with color coding
- Real-time statistics tracking for both strategies
- Animated gameplay showing each step
- Plot comparing win rates over multiple trials
- Comprehensive documentation in the Info tab

The simulation proves that switching doors gives approximately 67% win rate while staying gives approximately 33% win rate.
